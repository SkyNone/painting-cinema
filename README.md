# Painting Cinema｜名画电影化

把名画当作电影中被冻结的一帧：设计画中世界的一段可信动作，以连续运镜抵达原画构图，再恢复绘画质感并定格。

## 技能内容

- [主 Skill](painting-cinema/SKILL.md)：工作流程、动作与道具闭环、空间和时间检查、终点策略。
- [提示词模板](painting-cinema/references/prompt-template.md)：可裁剪的分镜与成片提示词骨架。
- [莫奈示例](painting-cinema/references/example-monet.md)：15 秒母子场景，展示持伞、拥抱与主动归位。
- [工具配置](painting-cinema/references/tool-config.md)：能力核对、模型经验和局部修正条件。

## 使用

将 `painting-cinema/` 目录放入所用 Agent 的技能目录，再提供原画与目标时长。例如：

> 用 painting-cinema 把这幅名画设计成 15 秒短片，先给连续分镜，最后自然回到原画。

默认先确认分镜；明确要求“直接生成”时可跳过分镜确认。实际视频生成依赖当前环境可用的图生视频工具，技能本身不提供模型服务或密钥。

## 本版规则

保留道具闭环、双手检查和归位顺序；按画作选择运镜，区分故事节拍、运镜阶段与独立贴近；明确先归位、再转换、最后定格；不强制提示词字数，不把历史模型经验当成固定能力。

主文件、模板与示例已做结构和分镜检查，并用静物场景完成文本试用。本版未进行真实视频生成验证；自然转场和终点吻合须在实际成片中检查。
