# 名画电影化（Painting Cinema）

把原画当作电影中被冻结的一帧：倒推一个可信的连续动作，让人物、道具与摄影机抵达这一帧，末段恢复原画质感并定格。默认第 0 帧已是画中真实世界，转换前不出现绘画纹理。

## 工作流程

1. **确定参考与目标**：取得足够清晰的原画，确认时长、比例和用途。未指定时默认 15 秒，比例服从原画。已有清晰参考不重复搜图；需要查资料时优先博物馆等可核对来源。区分画面事实与创作补全，不编造考证信息。
2. **建立终点清单**：核对主体数量、画面位置、朝向、姿态、遮挡、道具及持握、轮廓、地平线、光向和主色。区分画面左右与角色自身左右。需要扩图时保留完整主体与空间关系，明确采用的终点参考版本。
3. **找到核心动作**：围绕最打动人的情绪或动作倒推前因，再设计自然归位。15 秒默认 3–5 个故事节拍；必要时增加。减少独立动作任务、重复运镜和无关细节，同时保留主动作的完整过程与空间递进；动作超出时间预算时仍须删减。人物归位须有可信动机，不为恢复构图强加推、扔、摔或惊吓。
4. **设计连续运镜**：按空间选择跟随、侧移、推近、轻环绕或后撤，不固定三段套路。默认最多一次环绕、两次独立贴近。按摄影机实际运动计数：同一次贴近中观察多个细节不另算；拉开后再次靠近须另计，不能因一镜到底而忽略次数。镜头速度变化呼应主体动作与观察动机；跟随主体时减速可与其停步、受力相扣，观察者机位也可在主体停下后继续揭示环境。允许自然加减速、情绪停留和收尾停止，避免突兀急停、甩镜及机械往返。
5. **检查并写脚本**：通过下方闭环检查，按提示词结构写分镜。按需描述材质与外观，不强制字数；先写正向动作，再列通用风险和本画风险，删除重复及无关禁令。
6. **确认与生成**：默认先给原画分析、核心故事、带时间的连续分镜和终点策略。用户明确说“直接生成/不用确认”时跳过分镜确认。按当前工具支持的时长、比例、首尾帧、参考图和音频能力执行，不指定固定模型或升级顺序。没有视频工具时交付脚本，明确尚未生成。
7. **回读与修正**：实际生成后抽帧检查开场、核心动作、归位前、转换中和末帧，再完整播放并重点回看收尾。末帧吻合与转场连续须分别通过下方收尾检查；不能只看最后一帧。优先简化失败动作。仅在支持局部续接且边界机位、主体、光向和声音可衔接时重做片段，否则修正后重做整段。

## 闭环与可行性检查

- **手与道具**：逐角色核对每只手的占用和交接顺序。新增道具交代进入与退出动作，不能凭空消失或被丢弃腾手；优先不新增前景道具。
- **归位顺序**：先解决位置、遮挡与持握冲突，再恢复终点姿态。例如孩子先松开站定，母亲才恢复参考要求的持伞方式；具体手势必须依据原图，不套用案例。
- **环境点缀**：新增元素符合画中世界，不抢主体、不承担强行动机；原画未包含的元素须在转换前离开画面，否则删除。
- **空间连续**：相邻机位能够接续，摄影机不穿过人物或实体。拍正脸时交代如何到达可见机位；严格角色第一人称不能同时展示自身完整正脸。
- **信息递进**：每次移动带来新的空间、动作或情绪信息；可用前后景遮挡、光影、距离变化和主动作的自然延续丰富沿途，不为填满画面堆新事件。保留有意义的静止、环境观察和留白。
- **时间预算**：动作、路程、转角与归位能在分配时间内发生；时间段连续覆盖总时长。分别统计故事节拍、运镜阶段和贴近次数，不能把细节观察写成硬切。
- **冲突处理**：原画核心元素、终点构图与收尾连续性须同时成立，再保证动作和空间可信，最后增加次要细节。发生冲突时减少动作与运镜复杂度或增加收尾预算，不能牺牲连续性硬接原画。

## 首尾参考与收尾

原画或确认扩图是终点参考，开场另行设计。不能强制用油画作首帧，同时要求第 0 帧是不同机位的真人场景。

- 支持尾帧约束时使用终点参考；需要首帧时另准备与开场分镜一致的真人图。尾帧约束用于锁定目标，不代表中间过渡已经顺滑，仍须回读检查。
- 仅支持首帧时，用开场真人图生成，依能力提供终点参考或构图清单；精准恢复原画仍须实际验证，不能仅凭提示词保证。
- 接回困难时先提前完成归位、减少动作或简化路线，再增加收尾时间。不能用硬切、叠化重影、闪白、突然缩放、凭空出现画框或直接贴图遮掩错位。需要后期处理时说明方式，连续播放检查衔接；不自然则继续修正。

收尾按 **构图归位 → 材质转换 → 原画定格** 执行，三阶段属于同一段连续画面：

1. **构图归位**：在完整真实世界中，让人物完成动作、道具恢复持握，摄影机沿可行路线抵达原画视角并连续减速停稳。人物位置、主体尺度、朝向、遮挡、关键轮廓、地平线、光向与主色在此阶段对齐；风、衣料等微动提前减弱，不能在末尾急刹或瞬移归位。
2. **材质转换**：机位、人物姿态、道具与整体轮廓已稳定，原地将摄影细节连续凝练成原画笔触、色块或墨色；环境剩余微动平稳衰减至静止。保持画面亮度与色彩关系连续，不借转换调整构图，不出现双重轮廓、五官或道具跳变；应让观众感到同一个世界自然凝结为画。
3. **原画定格**：转换完成后完整呈现终点参考，保留可辨认的静止时间。定格承接上一帧，不在最后一帧突然替换成原画。声音若存在，保持自然延续或平滑收束，避免转场瞬间截断。

默认预留约 0.7 秒用于转换与定格，例如 0.3 秒转换、0.4 秒定格；归位及减速另计在此前的时间预算中。复杂画作或转场不顺时延长转换与定格，并相应缩短前段，不能为凑 0.7 秒而加速变形或骤停。不得到转换阶段才挪人、改道具或重新设计构图。

**收尾通过条件**：同时检查归位前的真人构图、转换中连续多帧和末帧；正常速度连续播放时，无轮廓或位置跳变、色光闪变、急刹、突兀静止或贴图切换，且末帧与终点参考一致。若末帧正确但过渡突兀，仍判为未通过。归位错位先修路径与动作，材质跳变先修转换与时间预算；实际生成回读前不能承诺已经丝滑。

## 提示词结构

按题材裁剪，保证动作因果与终点约束完整：

1. **总述**：时长、比例、画中世界、核心情绪、连续长镜头与收尾目标。
2. **主体与环境**：识别必需的人物、道具、空间、光向和主色；仅补充镜头可见且有用的细节。
3. **连续路线**：摄影机起点、主体可见面、移动动机，以及抵达终点的路径。
4. **时间分镜**：每段写起止时间、主要动作、手部与道具状态、摄影机路线和下一段如何接续。
5. **归位与转换**：分别写清动作归位、摄影机减速停稳、材质连续转换和静止定格的时间区间；确保归位完成在转换之前。
6. **风险约束**：禁止硬切、瞬移、穿模、人数或肢体突变、道具无故丢失；补充本画实际风险，避免近义词堆叠。

## 题材与声音

动作画围绕一个核心动作展开；肖像或静物采用微动作、材质观察和轻推近，不强加奔跑或拥抱。浮世绘、水墨、工笔采用符合画中世界的可信三维质感，末段恢复相应笔触与留白。抽象画采用色彩与形态演绎，不套用真人模块。

默认无对白、旁白和配乐，只保留与动作对应的主要环境音。工具不支持音频时另给声音设计，不声称已经生成同步音效；配乐按用户要求添加。

区分脚本检查与实际成片验证：只有生成并回读后，才能认定动作自然、转场顺滑、终点吻合。
