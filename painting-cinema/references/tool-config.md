# 工具能力与经验配置

生成前以当前可调用工具的文档和参数为准；以下原始模型名称仅是用户先前工作流的经验记录，不代表本环境已安装、已授权或这些版本仍可用。

## 能力核对

记录当前工具、模型、支持的时长/比例/分辨率/帧率、首帧/尾帧/多参考、音频、局部续接与费用或额度。先用实际支持的参数，不能把提示词中的 24fps 当作导出保证。文件上传方式与参考图字段按当前工具要求执行，不假定一定存在 FileBatchUpload 或 image_to_video。

遇到未知能力先查工具说明；没有生成工具时交付脚本、参数意图与待验证项，明确尚未生成。

## 先前测试经验（未经当前版本复测）

- 原工作流曾使用 `seedance_2.0_fast` 定动作，`seedance_2.5` 提升画质，并列过 `seedance_2.0`。
- “快模型更克制、高级模型更戏剧化”是特定任务观察，不是稳定的版本结论。
- 原稿记录的时长和比例范围须在调用前重新核对，不作为硬编码能力。

## 验证与模型切换

在用户授权范围内选择较低成本的可用配置验证动作、镜头与终点。升级画质时保留同一参考版本、故事、终点清单和路线，只调整必要参数。若动作退化，退回已验证版本或简化动作，不以“高级”名称替代比较。

记录画作与参考版本、模型版本、实际参数、提示词、失败时间点、修改内容及复测结果。区分未验证假设与已观察结果；只有实际抽帧和播放检查过的样本，才用于更新模型经验。

## 局部修正

仅在工具支持且前后衔接可验证时重做片段。固定相邻边界帧、人物与道具状态、光向、镜头朝向和运动速度，处理环境音衔接后播放检查。没有局部续接能力时修正提示词并重做整段；不能声称局部修正已完成。
