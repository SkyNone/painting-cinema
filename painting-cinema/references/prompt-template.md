# 成片提示词模板

先依据主 Skill 完成闭环与空间检查。以下是可裁剪骨架：保留核心动作、连续路径和终点策略，按题材选择模块，删除无关描述。不能把莫奈例子的拥抱、伞、放手、飞鸟或具体时间复制成通用规则。

## 一、设计记录（供脚本确认，不必全部送进生成模型）

- 参考：原画来源、已确认作品信息、用户选择的终点参考版本；标注扩图或裁切。
- 事实与演绎：分别列画面可见内容、资料确认内容与创作补全；无法确认处留白。
- 参数与能力：时长、比例、当前工具；首帧/尾帧/参考图/音频/局部重做的支持情况。
- 终点清单：主体数量、画面位置、姿态、朝向、持握、遮挡、轮廓、地平线、光向、主色。
- 核心故事：一句话情绪目标，一个核心动作；写出其前因与自然终点。
- 预算：15 秒默认 3–5 个故事节拍，最多 2 次独立贴近；单列运镜阶段。复杂任务说明为何需要增加节拍或时长。
- 路线：相邻机位如何接续，正脸或局部如何变得可见，摄影机能否通过。
- 收尾：归位完成时间、转换区间、静止定格区间；各区间连续覆盖全片。
- 风险：道具闭环、双手占用、归位顺序、临时元素退出、动作与路程预算。

## 二、生成提示词骨架

### 总述

{{时长}} 秒，{{比例}}，{{题材与时代地域}}，{{真实世界或对应画种的三维质感}}，{{主色情绪}}。采用一条连贯、平稳的长镜头；自然加减速，按情绪短暂停留，最终停止。第 0 帧已是画中世界，转换前保持真实质感。无对白、旁白和配乐；仅保留 {{与实际动作对应的主要环境音；不支持音频时移到声音设计}}。

围绕 {{一个核心动作}} 展开，{{起因→动作→自然归位}}。保留参考的 {{主体、道具、空间、光向与主色}}。终点遵循 {{终点参考与构图清单}}；{{如有临时元素，明确进入和退出路线}}。

### 主体与材质（按题材选择）

{{人物数量、可见外观与服饰、关键持握；或静物/船只/建筑等主体的材质与结构}}。{{只描述本镜头能看到且影响识别的细节}}。动作受力、织物惯性和环境反应可信。原画不清楚的细节采用低存在感、符合时代的演绎，不作为考证事实。

### 连续摄影路线

{{起点机位与可见面}} → {{核心动作阶段的侧移/跟随/推近/轻环绕}} → {{抵达终点的路径、朝向与减速}}。

写清每次换位的动机和空间；默认最多一次环绕、两次独立贴近。用摄影机与主体的相对运动改变景别，不用硬切。开场可用局部、前景或环境全景，以画作与路线需要决定。

### 按时间段的分镜

每段格式：

**【{{起—止秒}}｜{{一个主要动作}}】**
- 主体：{{谁先做什么、道具在哪只手、动作如何结束、下一段如何接续}}。
- 摄影机：{{位置/高度/朝向、可见主体的哪一面、路径与速度变化}}。
- 环境与情绪：{{少量会影响故事的光、风、遮挡和声音}}。

细分时间段服务于动作衔接，不要求一秒一镜；不能在极短段内堆奔跑、换手、大幅环绕和多个贴脸动作。焦段、机位高度和时间戳只在有用时给出；不把描述当作工具保证。

### 收尾

**【{{归位区间}}｜构图归位】**
{{主体主动完成动作并自然到位；先解决持握或遮挡，再恢复终点姿态}}。摄影机沿可实现路径抵达终点视角并减速停止。逐项对齐人数、画面坐标、遮挡、道具轮廓、透视、光向与主色；此时仍是完整真实世界。

**【{{转换区间}}｜材质转换】**
构图、人物姿态、关键道具与机位不再调整；环境运动连续衰减。{{摄影细节转成对应原画笔触、色块或墨色留白}}，保持同一场景轮廓与透视，不重新生成不同构图。

**【{{定格区间}}｜原画定格】**
完整呈现终点参考版本，所有运动停止，保留足够辨认时间。默认转换加定格约 0.7 秒，必要时延长；将增加的时间从前段预算中扣除。

### 简短风险约束

- 通用：无硬切、跳切、瞬移、穿模、肢体或人数突变、道具无故丢失、突兀加减速；转换前无绘画肌理，转换时不改构图。
- 本画：{{只列与这幅画有关的失败点，如先孩子归位再双手持伞、临时鸟在转换前离开、不能改变关键道具颜色}}。

## 三、提交前检查

1. 删除未替换占位符、无关模块和相互矛盾的描述。
2. 核对每段连续，结束时间等于总时长，收尾预算没有重复计入。
3. 分别统计故事节拍、运镜阶段与独立贴近；细节观察不另记一次贴近。
4. 核对每只手、道具进入退出、人物归位顺序、相邻机位与正脸可见性。
5. 单列工具参数与首尾参考图角色；若无法保证精准末帧或同步声音，明确标注待验证。
6. 先验证动作与收尾；真实成片通过后再增加次要细节和画质要求。
